{{- /* logo-img — a ministry logo from assets/, as an through Hugo's pipeline. Brand assets go through Hugo, not Cloudinary. An SVG is minified and fingerprinted as is; a raster is resized to 240px tall and served as WebP, enough for a strip mark at 2x. Either way the carries width and height (an SVG's from its viewBox), so the browser reserves the logo's box before it loads and the size classes only scale it. An SVG drawn in currentColor renders black inside an : fine on a light ground. A logo for a dark ground has to be inlined instead (icon.html). Params (dict): src (required) path under assets/, e.g. "img/ministries/ugo-mini.svg" alt (required) "" when a heading beside the logo already names it class (required) size classes, e.g. "h-16 w-auto" loading (optional) "lazy" (default) or "eager" for a logo above the fold */ -}} {{- if not (isset . "alt") -}} {{- errorf "logo-img: %s needs an alt, even an empty one" .src -}} {{- end -}} {{- with resources.Get .src -}} {{- $img := . -}} {{- $w := 0 -}} {{- $h := 0 -}} {{- if eq .MediaType.SubType "svg" -}} {{- /* The viewBox, as the illustration shortcode reads it. */ -}} {{- with index (findRESubmatch `viewBox="[\d.]+ [\d.]+ ([\d.]+) ([\d.]+)"` .Content 1) 0 -}} {{- $w = index . 1 -}} {{- $h = index . 2 -}} {{- else -}} {{- errorf "logo-img: %s has no viewBox to size it by" $.src -}} {{- end -}} {{- $img = . | minify | fingerprint -}} {{- else -}} {{- $img = .Resize "x240 webp" -}} {{- $w = $img.Width -}} {{- $h = $img.Height -}} {{- end -}} {{- else -}} {{- errorf "logo-img: %q is not in assets/" .src -}} {{- end -}}
