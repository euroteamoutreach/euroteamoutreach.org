{{- /* cloudinary-img — a responsive delivered from ETO's Cloudinary account. Builds delivery URLs from site.Params.cloudinaryBase (the public cloud name; API secrets never enter this repo, #60). Every width uses c_limit,f_auto,q_auto: c_limit never upscales an intrinsically small image, f_auto picks AVIF/WebP per browser, q_auto picks the compression. Cloudinary honors EXIF orientation on delivery by default, which the UGO field photos depend on (planning/copy/ugo.md "Build caveat — EXIF orientation"). Params (dict): src (required) Cloudinary public ID, e.g. "ugo/2025/bread-bakers" alt (required) alt text. Pass "" explicitly for a decorative image; omitting it fails the build, so no photo ships without a decision. sizes (optional) the sizes attribute; default "100vw". Set it to the rendered width (e.g. "(min-width: 1024px) 50vw, 100vw") or the browser over-fetches. class (optional) classes for the width (optional) intrinsic width, with height, to reserve layout space height (optional) intrinsic height loading (optional) "lazy" (default) or "eager". Use eager for the one above-the-fold hero; it also sets fetchpriority="high". crop (optional) a Cloudinary transformation applied before the resize, e.g. "c_crop,x_563,y_526,w_2816,h_2112", to frame part of the original. Cropping here, not with a CSS zoom, keeps the delivered pixels at full sharpness. Usage: {{ partial "cloudinary-img.html" (dict "src" "ugo/2025/bread-bakers" "alt" "Volunteers loading bread into a van" "sizes" "(min-width: 1024px) 33vw, 100vw") }} */ -}} {{- $src := .src -}} {{- if not $src -}} {{- errorf "cloudinary-img: 'src' is required" -}} {{- end -}} {{- /* A key holding nil (a caller passing a missing front-matter field) counts as missing: only an explicit "" means decorative. */ -}} {{- if or (not (isset . "alt")) (eq .alt nil) -}} {{- errorf "cloudinary-img: 'alt' is required for %q (pass \"\" for a decorative image)" $src -}} {{- end -}} {{- /* Widths cover phone at 1x through a full-bleed hero on a 1024px-wide 2x screen. The fallback src uses 1024, a sensible middle for browsers that ignore srcset. With a known width, candidates stop at the original's own width: c_limit never upscales, so a larger candidate would return the same pixels under a false "w" descriptor, and the browser, trusting it, would draw a w-auto image at a fraction of its size on a 2x screen. */ -}} {{- $widths := slice 480 768 1024 1536 2048 -}} {{- with .width -}} {{- $max := int . -}} {{- if lt $max 2048 -}} {{- $capped := slice -}} {{- range $widths }}{{ if lt . $max }}{{ $capped = $capped | append . }}{{ end }}{{ end -}} {{- $widths = $capped | append $max -}} {{- end -}} {{- end -}} {{- $crop := "" -}} {{- with .crop }}{{ $crop = printf "%s/" . }}{{ end -}} {{- $srcset := slice -}} {{- range $widths -}} {{- $srcset = $srcset | append (printf "%s/image/upload/%sc_limit,f_auto,q_auto,w_%d/%s %dw" site.Params.cloudinaryBase $crop . $src .) -}} {{- end -}} {{- $fallback := printf "%s/image/upload/%sc_limit,f_auto,q_auto,w_%d/%s" site.Params.cloudinaryBase $crop (int (math.Min 1024 (index $widths (sub (len $widths) 1)))) $src -}} {{- $loading := .loading | default "lazy" -}}
